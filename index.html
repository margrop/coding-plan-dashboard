Local quota console

Coding Plan 配额中心

统一查看各平台 Coding Plan 的限额、使用量、重置信息和数据更新时间。支持同一平台多账号。

数据采集

导入原始 curl：系统会根据接口 URL 自动识别平台类型。每个 curl 保存为独立账号，可添加备注区分。请求会保存到服务器 JSON 文件，页面每次打开或点击刷新时由服务器重新执行。注意：原始 curl 可能包含 Token/Cookie，会以明文保存在服务器。

服务器仅允许已配置的域名，使用无 shell 的方式执行。

新增火山方舟账号

无需抓包，直接填写 AccessKey ID / Secret Access Key 创建 CodingPlan 或 AgentPlan 账号。同一火山账号可分别创建 CodingPlan 和 AgentPlan 两个独立条目，并分别填写备注区分。需要在火山引擎控制台创建具备 ark:ListCodingPlan/ark:GetCodingPlanUsage（CodingPlan）以及 ark:GetAgentPlanAFPUsage（AgentPlan）权限的 RAM 凭据。

更新已有火山方舟账号的 AK/SK

在对应 CodingPlan / AgentPlan 卡片上点击「设置 AK/SK」即可为该账号配置 OpenAPI 凭据。配置后该账号将通过 OpenAPI 签名鉴权获取用量，无需 curl 中的 Cookie。

新增 Google AI 账号

填写 Antigravity / Gemini CLI 的 OAuth refresh token 创建 Google AI 账号，显示 Gemini Models 的 5 小时和周额度。refresh token 可在 ~/.gemini/antigravity-cli/antigravity-oauth-token（字段 token.refresh_token）或 ~/.gemini/oauth_creds.json 中找到。代理默认使用服务器环境变量 GOOGLE_AI_PROXY，可在此覆盖；不填则直接对外网请求。
